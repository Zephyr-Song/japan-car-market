# 日本汽车全球流通全链路

## 一、总览：三条路径

日本汽车走向世界有三条截然不同的路径，产业链完全分离，参与者和商业模式也不同：

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                         日本汽车全球流通三大路径                                │
│                                                                              │
│   ┌──────────────────┐  ┌──────────────────┐  ┌──────────────────────────┐  │
│   │  路径A: 新车出口  │  │ 路径B: 中古车出口 │  │ 路径C: 海外本地化生产   │  │
│   │  (整车贸易出口)   │  │ (二手车出口)      │  │ (海外建厂/CKD)          │  │
│   ├──────────────────┤  ├──────────────────┤  ├──────────────────────────┤  │
│   │ 主体: JAMA车企    │  │ 主体: 出口商      │  │ 主体: 日系车企海外子公司 │  │
│   │ 规模: 421.7万台/年│  │ 规模: ~80万台/年  │  │ 规模: ~1,700万台/年     │  │
│   │ 目的地: 北美/欧洲 │  │ 目的地: 发展中   │  │ 目的地: 全球就地生产    │  │
│   │  /亚洲/中东/大洋洲│  │  /俄罗斯/非洲/南美│  │                         │  │
│   │ 港口: 名古屋/横滨 │  │ 港口: 横滨/名古屋 │  │ 模式: CKD→SKD→CBU      │  │
│   │  /神户/大阪       │  │  /博多/大阪       │  │  →独资工厂              │  │
│   │ 运输: RoRo滚装船  │  │ 运输: RoRo/集装箱 │  │                         │  │
│   └──────────────────┘  └──────────────────┘  └──────────────────────────┘  │
│                                                                              │
```

## 二、路径A：新车出口（JAMA 统计口径）

### 2.1 产业链环节

```
日本国内工厂 ──→ 整备场/仓储 ──→ 出口港 ──→ 海运 ──→ 目的港 ──→ 当地经销商 ──→ 终端消费者
  (丰田/本田/    (车辆终检/PDI)   (报关)     (RoRo船)   (清关/缴税)   (4S店/直营)
   日产/铃木等)
```

### 2.2 主要出口港口

| 港口 | 地位 | 特点 |
|------|------|------|
| **名古屋港** | 第一大汽车出口港 | 丰田大本营，位于爱知县，汽车出口占全国 30% |
| **横滨港** | 第二大 | 服务首都圈，日产/本田主要出口通道 |
| **大阪港/神户港** | 关西双港 | 共享同一海关关区 |
| **博多港** | 九州入口 | 距离亚洲最近，东南亚航线起点 |

### 2.3 出口量按目的地区域（2024年 JAMA 数据）

| 地区 | 出口量（万台） | 占比 | 趋势 |
|------|-------------|------|------|
| 北美 | 160.1 | 38% | 持续恢复（USMCA 区域） |
| 欧洲 | 66.3 | 16% | 稳步增长 |
| 亚洲 | 58.3 | 14% | 稳定 |
| 中近东 | 52.6 | 12% | 增加 |
| 大洋洲 | 47.3 | 11% | 增长 |
| 中南美 | 26.5 | 6% | 缓慢恢复 |
| 非洲 | 9.6 | 2% | 停滞 |

### 2.4 运输方式

- **RoRo 滚装船**：主流方式，车辆直接开上/开下船舱，单车成本低
- **专用汽车船（PCTC）**：Pure Car Truck Carrier，可载 5,000-8,000 台
- **集装箱**：高价值车辆或小批量出口时使用
- 主要船公司：NYK Line、MOL（商船三井）、K Line（川崎汽船）

### 环节 1：车辆来源

车辆进入二手市场的四条来源通道：

```
  ┌──────────────────────────────────────────────────────┐
  │                  日本二手车来源                        │
  │                                                      │
  │  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────┐ │
  │  │ 4S店置换 │  │ 个人出售  │  │ 租赁车   │  │ 事故 │ │
  │  │ (主要    │  │ (中古车  │  │ 下线     │  │ 维修 │ │
  │  │  通道)   │  │  店/拍卖)│  │          │  │  车  │ │
  │  └────┬─────┘  └────┬─────┘  └────┬─────┘  └──┬───┘ │
  │       │             │             │            │     │
  └───────┼─────────────┼─────────────┼────────────┼─────┘
          │             │             │            │
          ▼             ▼             ▼            ▼
        ┌─────────────────────────────────────────────┐
        │              进入拍卖流通渠道                  │
        │         (4S置换车占拍卖车辆的最大比例)         │
        └─────────────────────────────────────────────┘
```

**说明**：
- **4S 店置换**：车主换购新车时，旧车被经销商收走，是最主要的拍卖车辆来源
- **个人直接出售**：通过中古车店或直接委托拍卖
- **租赁车下线**：租赁公司淘汰的车辆，车龄通常 3-5 年
- **事故车/维修车**：维修后流入二手市场，会被标注事故记录

```
  │  │·登记证书   │    │·车体外观   │    │·漆面厚度   │               │
```

#### AIS 评分标准（11 级 + 外观/内饰各 5 级）

| 评分 | 含义 | 里程 | 车龄 | 车况描述 |
|------|------|------|------|---------|
| **S** | 最高级 | <1万km | <1年 | 无事故、无修理记录，接近新车 |
| **6** | 极优 | <3万km | <3年 | 无事故、无修理或极小损伤不需修理 |
| **5** | 优 | <6万km | — | 无事故、仅极小剐蹭，无需修理 |
| **4.5** | 良+ | <10万km | — | 需小修理可达 5 分，车内外极好 |
| **4** | 良 | <10万km | — | 外观有剐蹭损伤需修理，车内外良好 |
| **3.5** | 中+ | >10万km | — | 外观有不少损伤需修理，车况良好 |
| **3** | 中 | >10万km | — | 很多损伤必须修理，车况一般 |
| **2** | 差 | — | — | 破车，各种问题 |
| **1** | 事故 | — | — | 事故车无法驾驶，或大量改装非原厂 |
| **R/A** | 重大事故 | — | — | 有严重事故记录并修复的车辆 |
| **\*** | 无法评级 | — | — | 无法评级 |

> **市场实际流通**：经销商保有量最大的是 **4 分和 4.5 分**两个等级。4 分以上能基本保证日常使用。6 和 S 级价格接近新车。

#### 检查表包含的关键信息

| 项目 | 内容 |
|------|------|
| 车辆数据 | 登记号、底盘号、首次注册年月 |
| 结构性损坏 | A/B/C 柱、纵梁、减震器悬挂部位 |
| 外观损坏 | 27 个检查部位（前保险杠到后保险杠） |
| 机械损坏 | 发动机、变速箱、制动系统 |
| 综合评级 | S / 6 / 5 / 4.5 / 4 / 3.5 / 3 / 2 / 1 / R/A / * |
| 外观评级 | A / B / C / D / E（5 级） |
| 内饰评级 | A / B / C / D / E（5 级） |
| 设备清单 | 合金轮毂、天窗、导航等 |
| 评估员注释 | 日语书写，需翻译 |

## 六、制度保障体系

日本二手车全球流通的品质信誉，建立在以下制度基础上：

| 制度/组织 | 作用 | 影响 |
|-----------|------|------|
| **法定车检（shaken）** | 每 2 年强制检验，车况有法律保障 | 二手车品质透明，出口信誉好 |
| **AIS 评估制度** | 丰田/日产/本田出资的第三方评估（1996 年创立） | 10 级评分标准化车况描述 |
| **NAK（二手车拍卖行业协会）** | 2001 年成立，统一里程管理系统 | 彻底解决改表问题 |
| **JAMA** | 日本自动车工业会 | 统计生产/出口/海外生产，官方数据来源 |
| **JAIA** | 日本自动车输入组合 | 统计进口车 |
| **JADA** | 日本自动车贩卖协会连合会 | 品牌别注册统计，新车销量数据 |
| **全軽自協** | 全国轻自动车协会连合会 | K-car 数据来源 |
| **AUCNET** | 日本最大拍卖居间平台 | 70-80% 拍卖场接入，年居间 480 万台 |
| **旧货经营法** | 二手车经营许可制度 | 经营者需持牌 |
| **汽车再循环法** | 废车回收法律 | 出口前的车辆注销流程规范 |

### 日本汽车流通的核心认知

1. **三条路径并行**：新车出口（422 万）、中古车出口（80 万）、海外生产（1,700 万），规模差异巨大
2. **拍卖是二手车流通的枢纽**：127 个拍卖场 + AUCNET 平台，年流转 480 万台
3. **海外生产是真正的主力**：是出口量的 4 倍，亚洲占比 52% 且仍在高速增长
4. **中古车出口面向发展中国家**：俄罗斯/非洲/南美/东南亚，与中国新车出口存在直接竞争
5. **日本进口市场高度封闭**：德系占 45%，中国仅 3.8%，K-car 税制壁垒使 40% 市场对外资物理隔绝
6. **制度保障是流通效率的基石**：法定车检 + AIS 评估 + NAK 里程系统 + 旧货经营法，确保了全球流通的品质信誉
