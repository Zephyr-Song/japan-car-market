**建议**：
- 按 `crawlers/` → `processors/` → `analyzers/` → `utils/` 重新组织
- 一次性脚本移到 `scripts/oneoff/` 或直接删除
- `__pycache__/` 加入 `.gitignore`（当前已提交 pyc 文件）

#### 1.2 `__pycache__` 被提交到仓库

`.gitignore` 中可能未正确排除 `__pycache__`，导致 `src/__pycache__/` 下 7 个 `.pyc` 文件进入版本控制。

**建议**：
```gitignore
__pycache__/
*.pyc
*.pyo
```
执行 `git rm -r --cached src/__pycache__` 清理。

#### 1.3 `requirements.txt` 缺少版本锁定

```
playwright
pandas
plotly
...
```
所有依赖未指定版本，可能导致 reproducibility 问题。**建议**用 `pip freeze > requirements.txt` 锁定版本，或使用 `pyproject.toml` + `poetry.lock`。

#### 1.4 README 编码问题

README 中大量 emoji 和中文出现乱码（如 `??` 替代了 emoji），说明文件编码或 GitHub 渲染存在问题。**建议**检查文件是否为 UTF-8 无 BOM 编码。

### 二、数据架构问题

#### 2.1 数据库表缺乏索引

`used_cars_cleaned` 表有 1,113 条记录，但没有定义任何索引。随着数据增长，按 `brand_clean`、`year_ce`、`prefecture` 等字段查询会变慢。

**建议**：
```sql
CREATE INDEX idx_brand ON used_cars_cleaned(brand_clean);
CREATE INDEX idx_year ON used_cars_cleaned(year_ce);
CREATE INDEX idx_pref ON used_cars_cleaned(prefecture);
CREATE INDEX idx_class ON used_cars_cleaned(vehicle_class);
```

#### 2.2 数据管线缺乏幂等性

大量 `recalc_*`、`reparse_*`、`fix*`、`cleanup*` 脚本的存在说明：每次数据更新后需要手动修补。这表明 ETL 管线设计上不是幂等的（重新运行会产生重复数据或错误）。

**建议**：
- `process.py` 应设计为 `DROP → CREATE → INSERT` 模式或 `UPSERT` 模式
- 增加 `id` 唯一约束 + `ON CONFLICT REPLACE`
- 数据刷新脚本应能安全地反复执行

#### 2.3 CSV 和 SQLite 双存储冗余

`used_cars_cleaned.csv`（483KB）和 `japan_car_market.db`（4MB）同时存在，数据重复。CSV 是数据库的导出快照，但缺乏自动同步机制。

**建议**：以 SQLite 为唯一 source of truth，CSV 作为 dashboard 的只读导出。

## 第二部分：日本汽车全球流通全链路梳理

### 一、总览：日本汽车全球流通的三条主线

日本汽车走向世界有三条截然不同的路径，它们在产业链上完全分离，参与者和商业模式也不同：

```
┌─────────────────────────────────────────────────────────────────────┐
│                     日本汽车全球流通三大路径                           │
├─────────────────┬──────────────────┬─────────────────────────────────┤
│  路径A: 新车出口   │  路径B: 中古车出口  │  路径C: 海外本地化生产        │
│  (整车贸易出口)    │  (二手车出口)      │  (海外建厂/CKD)              │
├─────────────────┼──────────────────┼─────────────────────────────────┤
│ 主体: JAMA车企    │ 主体: 出口商       │ 主体: 日系车企海外子公司        │
│ 规模: 421.7万台/年│  规模: ~80万台/年   │ 规模: ~1,700万台/年           │
│ 目的地: 北美/欧洲  │ 目的地: 发展中国家  │ 目的地: 全球就地生产就地销售    │
│  /亚洲/中东/大洋州 │  /俄罗斯/非洲/南美  │                               │
│ 港口: 名古屋/横滨  │ 港口: 横滨/名古屋   │ 模式: CKD→SKD→CBU→独资工厂    │
│  /神户/大阪       │  /博多/大阪         │                               │
│ 运输: RoRo滚装船  │ 运输: RoRo/集装箱   │                               │
│  /专用汽车船       │                    │                               │
└─────────────────┴──────────────────┴─────────────────────────────────┘
```

**2024 年规模对比：**
- 新车出口：421.7 万台
- 中古车出口：约 80 万台（2025H1 已达 82.6 万台，全年可能突破 160 万台）
- 海外生产：约 1,700 万台（是出口量的 4 倍）
- **合计：约 2,200 万台**，占日本汽车产量的绝大部分

### 二、路径 A：新车出口（JAMA 统计口径）

#### 2.1 产业链环节

```
日本国内工厂 ──→ 整备场/仓储 ──→ 出口港 ──→ 海运 ──→ 目的港 ──→ 当地经销商 ──→ 终端消费者
  (丰田/本田/  (车辆终检/PDI)   (报关)     (RoRo船)   (清关/缴税)   (4S店/直营)
   日产/铃木等)
```

#### 2.2 主要出口港口

| 港口 | 地位 | 特点 |
|------|------|------|
| **名古屋港** | 第一大汽车出口港 | 丰田大本营，位于爱知县，汽车出口占全国 30% |
| **横滨港** | 第二大 | 服务首都圈，日产/本田主要出口通道 |
| **大阪港/神户港** | 关西双港 | 共享同一海关关区 |
| **博多港** | 九州入口 | 距离亚洲最近，东南亚航线起点 |

#### 2.3 出口量按目的地区域（2024 年 JAMA 数据）

| 地区 | 出口量（万台） | 占比 | 趋势 |
|------|-------------|------|------|
| 北美 | 160.1 | 38% | 持续恢复（USMCA 区域） |
| 欧洲 | 66.3 | 16% | 稳步增长 |
| 亚洲 | 58.3 | 14% | 稳定 |
| 中近东 | 52.6 | 12% | 增加 |
| 大洋州 | 47.3 | 11% | 增长 |
| 中南美 | 26.5 | 6% | 缓慢恢复 |
| 非洲 | 9.6 | 2% | 停滞 |

#### 2.4 运输方式

- **RoRo 滚装船**：主流方式，车辆直接开上/开下船舱，单车成本低
- **专用汽车船（PCTC）**：Pure Car Truck Carrier，可载 5,000-8,000 台
- **集装箱**：高价值车辆或小批量出口时使用
- 主要船公司：NYK Line、MOL（商船三井）、K Line（川崎汽船）

### 三、路径 B：中古车出口（jumv.net 统计口径）

#### 3.1 产业链全链路

这是最复杂的一条路径，涉及多个中间环节：

```
                        ┌─── USS 拍卖（市场份额 40%）──┐
                        │                              │
日本车主 ─→ 4S店置换 ─→├─── JAA 拍卖 ─────────────────┤ ─→ 出口商 ─→ 整备/仓储 ─→ 出口港 ─→ RoRo船 ─→ 目的港 ─→ 当地进口商 ─→ 清关缴税 ─→ 零售商 ─→ 消费者
              或        │                              │  (BeForward等)  (ETC注销/      (日本海关     (当地关税/    (二手车
           个人直接出售  ├─── JU 拍卖（中小企业联合体）──┤                   车辆注销)      出口许可)     VAT/消费税)   经销商)
                        │                              │
                        └─── AUCNET 远程拍卖 ──────────┘
```

#### 3.2 关键环节详解

**环节 1：车辆来源**

- 4S 店置换：车主换购新车时，旧车被经销商收走
- 个人直接出售：通过中古车店或拍卖
- 租赁车下线：租赁公司淘汰的车辆
- 事故车/维修车：维修后流入二手市场

**环节 2：拍卖体系（日本二手车流通的核心）**

日本有 **127 个拍卖场**，分三大体系：

| 体系 | 代表 | 市场份额 | 特点 |
|------|------|---------|------|
| 企业联合体系 | USS | 64% | 日本最大，总部名古屋，周处理 10 万+台 |
| 主机厂体系 | 丰田/日产自有拍卖 | 18% | 为经销商解决置换车销路 |
| 中小企业联合体 | JU（日本二手车协会） | 18% | 面向中小经销商 |

**AUCNET 平台**：日本最大的汽车拍卖居间平台，70-80% 的拍卖场接入 AUCNET。每年通过 AUCNET 居间拍卖的车辆达 480 万台。14,000+ 会员既是买家也是卖家。

**车辆检查制度**：
- 所有车辆拍卖前必须经过专业评估
- 评估由 **AIS**（丰田/日产/本田等出资组建的最大民营评估公司）等机构完成
- 检查表（検査表）包含：
  - 车辆数据（登记号、底盘号）
  - 结构性损坏
  - 外观损坏
  - 机械损坏
  - **评级**（0-10 分，如 4.5 分）
  - 设备清单
  - 评估员注释

**环节 3：出口商采购**

- 出口商必须是拍卖会会员（持有二手车交易许可证）
- 主要出口商：BeForward（日本最大）、Integrity Exports、Elegant Import & Export、MDK Japan 等
- 出口商根据目的国需求选车：俄罗斯要越野/SUV、非洲要耐用轿车、蒙古要混合动力

**环节 4：整备与注销**

- 车辆整备：清洗、维修、更换磨损件
- ETC 注销：注销高速 ETC 设备
- 车辆注销：向运输局提交注销申请
- 出口公申请书：取得出口许可（通常 2-5 天）

**环节 5：海运出口**

- 从拍卖场/出口商仓库运至港口
- 主要出口港：横滨、名古屋、大阪、神户、博多
- 运输方式：
  - **RoRo 滚装船**（主流，成本低，$300-500/台到东南亚）
  - **集装箱**（高价值车辆或小批量）
- 主要航线：日本 → 俄罗斯符拉迪沃斯托克（3 天）、东南亚（5-8 天）、非洲（20-30 天）、南美（30-40 天）、大洋洲（13-15 天）

**环节 6：目的国清关**

- 各国关税政策不同：
  - 俄罗斯：右舵车可以直接上路
  - 蒙古：混合动力车享受关税优惠
  - 坦桑尼亚/肯尼亚：年限限制（通常 7-10 年以内）
  - 智利：无年限限制但需排放达标
  - 新西兰：需通过合规检查（NZTA）
  - 斯里兰卡：2025 年重新开放二手车进口

#### 3.3 中古车出口目的国 Top10（2026 年 5 月数据）

| 排名 | 目的国 | 出口量（台） | 区域 | 特征 |
|------|--------|-----------|------|------|

### 四、路径 C：海外本地化生产（JAMA 海外生产统计）

#### 4.1 发展阶段

```
1950s-1970s    →    1970s-1980s    →    1980s-2000s    →    2000s-至今
出口贸易阶段       贸易摩擦阶段        海外建厂阶段        全球融合阶段
(整车出口)        (自主出口限制)      (CKD→独资工厂)     (本地化研发+生产)
  100万台           168-230万台         450-1000万台        ~1700万台
```

**四个阶段的关键转折点：**

| 阶段 | 时间 | 驱动力 | 规模 |
|------|------|--------|------|
| 贸易出口 | 1970-1980 | 石油危机，日系省油车全球需求暴增 | 100→450 万台 |
| 自主限制 | 1981-1994 | 日美贸易摩擦，日本自主限制对美出口 | 168-230 万台/年 |
| 海外建厂 | 1980-2000 | 为绕过贸易壁垒，在美国/欧洲建厂 | 450→1000 万台 |
| 全球融合 | 2000-至今 | 中国/东南亚市场爆发，亚洲产能大转移 | 1000→2500 万台 |

#### 4.2 海外生产基地布局

**第一阶段：美国（1980s）**
- 丰田 Georgetown 工厂（1988 年，肯塔基州）
- 本田 Marysville 工厂（1982 年，俄亥俄州）
- 日产 Smyrna 工厂（1983 年，田纳西州）
- 日系在美共设 14 个汽车工厂 + 13 个零部件工厂
- 加拿大 4 个汽车工厂 + 1 个零部件工厂

**第二阶段：欧洲（1990s）**
- 英国 18 个汽车工厂 + 5 个零部件工厂
- 法国/西班牙/比利时各有布局

**第三阶段：亚洲（2000s-至今）**
- 泰国：日系"亚洲底特律"布局核心
- 印尼：丰田/本田生产基地
- 中国：丰田/本田/日产合资工厂
- 印度：铃木主导
- 越南/马来西亚：零部件基地

**亚洲海外生产暴增**：2024 年亚洲生产 882.6 万台，较 2023 年增长 29%。

#### 4.3 海外生产规模（2024 年估算）

| 地区 | 海外生产量（万台） | 占比 |
|------|---------------|------|
| 亚洲 | 882.6 | ~52% |
| 北美 | ~300 | ~18% |
| 欧洲 | ~123 | ~7% |
| 中南美 | ~41 | ~2% |
| 其他 | ~350 | ~21% |
| **合计** | **~1,700** | **100%** |

**关键结论**：日本汽车"出海"的主力不是出口，而是海外生产。海外生产量是出口量的 4 倍。

### 七、日本汽车流通体系的制度保障

| 制度/组织 | 作用 | 影响 |
|-----------|------|------|
| **法定车检（shaken）** | 每2年强制检验，车况有法律保障 | 二手车品质透明，出口信誉好 |
| **AIS评估制度** | 丰田/日产/本田出资的第三方评估 | 10级评分标准化车况描述 |
| **NAK（二手车拍卖行业协会）** | 2001年成立，统一里程管理系统 | 彻底解决改表问题 |
| **JAMA** | 日本自动车工业会，统计生产/出口/海外生产 | 官方数据来源 |
| **JAIA** | 日本自动车输入组合，统计进口车 | 进口数据来源 |
| **JADA** | 日本自动车贩卖协会连合会，品牌别注册统计 | 新车销量数据 |
| **全軽自協** | 全国轻自动车协会连合会 | K-car 数据来源 |
| **AUCNET** | 日本最大拍卖居间平台 | 70-80%拍卖场接入，年居间480万台 |
| **旧货经营法** | 二手车经营许可制度 | 经营者需持牌 |
| **汽车再循环法** | 废车回收法律 | 出口前的车辆注销流程规范 |

### 日本汽车流通的核心认知

1. **三条路径并行**：新车出口（422 万）、中古车出口（80 万）、海外生产（1,700 万），规模差异巨大
2. **拍卖是二手车流通的枢纽**：127 个拍卖场 + AUCNET 平台，年流转 480 万台
3. **海外生产是真正的主力**：是出口量的 4 倍，亚洲占比 52% 且仍在高速增长
4. **中古车出口面向发展中国家**：俄罗斯/非洲/南美/东南亚，与中国新车出口存在直接竞争
5. **日本进口市场高度封闭**：德系占 45%，中国仅 3.8%，K-car 税制壁垒使 40% 市场对外资物理隔绝
6. **制度保障是流通效率的基石**：法定车检 + AIS 评估 + NAK 里程系统 + 旧货经营法，确保了全球流通的品质信誉
